MvDeveloper — Site estático azul neon com pedido de orçamento pelo WhatsApp.

O que foi configurado:
- O cliente preenche o formulário e clica em "Enviar orçamento pelo WhatsApp".
- Uma nova aba abre uma conversa com a mensagem pré-preenchida para o número comercial informado.
- O cliente precisa tocar em Enviar no WhatsApp para concluir.
- Se a abertura automática for bloqueada, o botão "Abrir WhatsApp" aparece com o link pronto.
- No rodapé também há um atalho para o WhatsApp.

Não é necessária API nem variável de ambiente. Nenhum pedido é salvo em banco de dados ou enviado automaticamente sem confirmação do cliente.

Para publicar, envie os quatro arquivos (index.html, style.css, script.js e este LEIA-ME) para a raiz do seu repositório e use Render Static Site com Publish Directory ".".

ATENÇÃO: Como o número foi configurado no código de um site público, visitantes poderão vê-lo e entrar em contato. Para trocar, edite WHATSAPP_NUMBER no script.js e o link do rodapé em index.html.
